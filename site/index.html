What kind of answer?

A number, a category, a forecast, a grouping. This decides the paradigm before data ranks the models.

Does row order matter?

Sets axis 2. If order carries signal, validation must respect time and most i.i.d. models drop out.

How does new data arrive?

Decides which drift checkers can run at all. A detector that compares two batches has nothing to compare in a stream, and a streaming detector has no running error rate in a batch job.

Do the true answers arrive later?

Detectors that watch the error rate need labels to come back. Without them you can only watch the data itself move, not whether the model got worse.
